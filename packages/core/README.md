# @selfbuilding/core

Dynamic workflows with sandboxes, run locally or handed to Trigger.dev. This package holds `factory`, `agent`,
`Agent.fromSkill`, `pipeline`, `parallel`, `sandbox()`, `ask`, sizes, journals, the plain Node host, the
error classes and the shared types every other package builds on.

```sh
pnpm add @selfbuilding/core
```

Requires Node 22.12 or later. Pre-release.
