# @selfbuilding/sandbox-impello

The Impello sandbox provider, `impello()`, and `impelloImageBuilder()` for its templates.

```sh
pnpm add @selfbuilding/sandbox-impello
```

Requires Node 22.12 or later. Pre-release.
