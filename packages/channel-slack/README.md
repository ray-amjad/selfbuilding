# @selfbuilding/channel-slack

A Slack channel for asks: `slack()` posts an agent's question with buttons or a reply form and routes the answer
back to the run. `slack-app-manifest.json` creates the Slack app with the scopes and events it needs.

```sh
pnpm add @selfbuilding/channel-slack
```

Requires Node 22.12 or later. Pre-release.
