# @selfbuilding/agents

The built-in agents and factories: `ImplementSpec`, `CodeReview`, `Verify`, `FindFlows`, the `shipChange`
factory and `verifyFlows`. Each agent is defined from a skill folder under `skills/`, which ships with the package.

```sh
pnpm add @selfbuilding/agents @selfbuilding/core
```

Requires Node 22.12 or later. Pre-release.
