# @selfbuilding/hooks

Fetch handlers (`(request) => Response`) to mount in any server: `createHitlHandler` receives channel
webhooks such as Slack answers, and `createCallbackHandler` receives signed wake-ups from sandboxes.

```sh
pnpm add @selfbuilding/hooks
```

Requires Node 22.12 or later. Pre-release.
