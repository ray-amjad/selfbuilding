# @selfbuilding/runtime

The in-sandbox runtime and the `selfbuilding-mcp` tool server, shipped as bundled files under `dist/`.
`@selfbuilding/core` copies them into each sandbox; you normally install this package and never import it.

```sh
pnpm add @selfbuilding/runtime
```

Requires Node 22.12 or later. Pre-release.
