# @selfbuilding/skills

Loads and validates `SKILL.md` folders and their sidecar contracts (`loadSkill`, `loadSkills`), and generates
typed bindings for them. `Agent.fromSkill` in `@selfbuilding/core` uses it.

```sh
pnpm add @selfbuilding/skills
```

Requires Node 22.12 or later. Pre-release.
