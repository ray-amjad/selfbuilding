# @selfbuilding/sandbox-conformance

The test suites a sandbox provider must pass: `describeSandboxProvider()` for the provider contract and
`describePlacement()` for placement. Both are vitest suites; call them from a provider's own tests.

```sh
pnpm add -D @selfbuilding/sandbox-conformance vitest
```

Requires Node 22.12 or later. Pre-release.
