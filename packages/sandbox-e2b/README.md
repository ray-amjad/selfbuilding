# @selfbuilding/sandbox-e2b

The E2B sandbox provider, `e2b()`, and `e2bImageBuilder()` for its templates. The `./adapter` export is the
shared adapter other E2B-shaped providers build on.

```sh
pnpm add @selfbuilding/sandbox-e2b
```

Requires Node 22.12 or later. Pre-release.
