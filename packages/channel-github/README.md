# @selfbuilding/channel-github

GitHub access for runs: `githubApp()` brokers short-lived installation tokens for clones and pushes, `pat()` is
the personal-access-token fallback, and the PR helpers open or update the pull request a run produces.

```sh
pnpm add @selfbuilding/channel-github
```

Requires Node 22.12 or later. Pre-release.
