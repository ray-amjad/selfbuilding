# @selfbuilding/harnesses

Harness adapters: how an agent CLI is installed, authenticated, started and parsed inside a sandbox. Import
`claudeCode()` from `@selfbuilding/harnesses/claude-code` and `codex()` from `@selfbuilding/harnesses/codex`.

```sh
pnpm add @selfbuilding/harnesses
```

Requires Node 22.12 or later. Pre-release.
