# selfbuilding

The `selfbuilding` command: `init` scaffolds a config and an example factory, `doctor` checks the config and every
credential, `run`, `resume`, `watch` and `cancel` drive runs on the plain Node host, `start` runs a workflow
script, `answer` replies to an ask, `reap` sweeps leaked sandboxes and `images build` builds provider templates.
Run `selfbuilding <command> --help` for the options.

```sh
pnpm add -D selfbuilding
```

Requires Node 22.12 or later. Pre-release.
